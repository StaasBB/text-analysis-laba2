предложения идут в следующем порядке

Например, если у слова 3 определения:
Номер предложения/Эталонное значение
1	/1
2	/2
3	/3
4	/1
5	/2
6	/3
7	/1
8	/2

Если определений 4, последовательность будет 1, 2, 3, 4, 1, 2, 3, 4.
